# dot-files

## What's this

karia's dot-files!!!

## Usage (Auto deploy for macOS)

Use this script: https://github.com/karia/setup-mac

## Usage (Manual deploy)

```
ghq get karia/dot-files   # => ~/ghq/github.com/karia/dot-files

cd ~
ln -s ~/ghq/github.com/karia/dot-files/.* .
```

## powerlevel10k

`.p10k.zsh` is generated by `p10k configure` from the `config/p10k-classic.zsh` template of
[romkatv/powerlevel10k](https://github.com/romkatv/powerlevel10k).
The answers given to the wizard are recorded in the `Wizard options` line at the top of the file,
and the `checksum` line identifies the template revision the file is based on.

powerlevel10k is distributed under the MIT License.
The full text is in [LICENSES/powerlevel10k-MIT.txt](LICENSES/powerlevel10k-MIT.txt).

### Keeping the symlink

`p10k configure` deletes the target file before writing to it,
so re-running the wizard replaces the `~/.p10k.zsh` symlink with a regular file.
Move the generated file back into this repository and recreate the symlink afterwards.
